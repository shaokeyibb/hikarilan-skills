# minimal-design-gate

**English** | [简体中文](README.zh-CN.md)

Minimal design. Every design starts with the minimal proposal and explains why nothing simpler works, checks itself for over-design, keeps no compatibility leftovers, and prefers an open-source solution wherever one exists.

## Install

```bash
npx skills add shaokeyibb/hikarilan-skills --skill minimal-design-gate
```

Add `-g` to install for your user rather than for the current project.

The full skill is in [SKILL.md](SKILL.md); the rest of the collection is listed in the [repository README](../../README.md).
