# minimal-design-gate

[English](README.md) | **简体中文**

最小化需求设计。任何需求设计都考虑先给最小方案，并说明为什么不能更简单，并考虑是否存在过度设计，不保留兼容遗留代码，有开源方案优先采用开源方案。

## 安装

```bash
npx skills add shaokeyibb/hikarilan-skills --skill minimal-design-gate
```

加上 `-g` 则装到用户级，而不是当前项目。

完整内容见 [SKILL.md](SKILL.md)；合集里的其他 skill 见[仓库首页](../../README.zh-CN.md)。
