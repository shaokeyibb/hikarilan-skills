# llm-agent-surface

**English** | [简体中文](README.zh-CN.md)

Best practices for building agent applications: when to let the model make semantic judgements and when the framework should decide deterministically, keeping the model's input and output surface as lean as possible, and assuming by default that the model's output is right.

## Install

```bash
npx skills add shaokeyibb/hikarilan-skills --skill llm-agent-surface
```

Add `-g` to install for your user rather than for the current project.

The full skill is in [SKILL.md](SKILL.md); the rest of the collection is listed in the [repository README](../../README.md).
