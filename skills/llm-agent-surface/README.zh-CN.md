# llm-agent-surface

[English](README.md) | **简体中文**

Agent 应用开发最佳实践。什么时候该用大模型来做语义识别，什么时候该让框架做确定性处理，模型的输入输出面尽量保证精简，默认模型输出一定是对的。

## 安装

```bash
npx skills add shaokeyibb/hikarilan-skills --skill llm-agent-surface
```

加上 `-g` 则装到用户级，而不是当前项目。
