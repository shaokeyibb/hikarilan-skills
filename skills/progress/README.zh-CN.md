# progress

[English](README.md) | **简体中文**

一个指令让 agent 回报当前进展，每次都是同一种表格：现在在做什么、之后还要做什么、还有哪些没做、哪些已经做完、还要做多久、进度如何。报告依据真实状态（任务列表、账本、`git`、后台任务），不靠记忆；耗时只按可度量的依据估算；报告期间不开始、不完成、也不改动任何事。

## 用法

| 你输入 | 你得到 |
|---|---|
| `/progress` | 标准报告：一张事项表，每项带状态（进行中、下一步、未完成、已完成），再加一行剩余时间与进度。 |
| `/progress 有什么风险？` | 标准报告，外加一张问答表，回答你额外问的内容。 |

传入的任何参数都是在报告之外的额外询问。如果参数是要它动手（修复、运行、继续），报告里不会去做，它会说明并询问你。

## 安装

```bash
npx skills add shaokeyibb/hikarilan-skills --skill progress
```

加上 `-g` 则装到用户级，而不是当前项目。
